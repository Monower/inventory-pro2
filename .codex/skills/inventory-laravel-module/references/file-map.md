# File Map

Use this map to pick the right files quickly.

- Entry routes: `routes/web.php`, `routes/auth.php`
- Module routes: `routes/modules/*Routes.php`
- Controllers: `app/Http/Controllers/*.php`
- Models: `app/Models/*.php`
- Migrations: `database/migrations/*.php`
- Seeders: `database/seeders/*.php`
- Inertia app entry: `resources/js/app.jsx`
- Pages: `resources/js/Pages/**`
- Shared components: `resources/js/Components/**`
- Build config: `vite.config.js`, `package.json`
